# i18n + menu logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve UI language from Recalbox `system.language` (es/en), apply catalogs to `/` and MiniRA, add `INSTALL.en.md`, and show Recalbox logo on `/` when in menu state.

**Architecture:** `np/locale.py` reads conf/`NP_LANG` → `"lang"` on `/api/now`; static `www/i18n/{es,en}.json`; clients use `t()` + `data-i18n`; index menu art uses `/system-logo?id=recalbox`.

**Tech Stack:** Python 3 stdlib, unittest, static HTML/JS on Recalbox Pi.

## Global Constraints

- No pip dependencies
- Supported langs: `es`, `en`; else fallback `en`
- Cache resolved lang 60s in process
- Source of truth for server code: also sync `now-playing/pi/`
